AI Configuration (Web & On-Device Voice Brain)

When you talk to Stack-Chan, its built-in voice pipeline uses the MCP bridge (ask_ai) to query your selected model (Gemini, Claude, or GPT) instead of the default cloud Qwen model. For 100% direct Gemini/Claude/GPT without any Qwen router, visit xiaozhi.me console for device DC:B4:D9:77:1A:58 or say "Ask Gemini…" / "Use ask_ai…".

Set GEMINI_API_KEY in .env — the server hot-reloads .env automatically as soon as you save!

Only your typed or spoken text goes to the chosen provider. The webcam is never sent anywhere.
